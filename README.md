# dhruv-kapri.github.io

Source of my personal website: **https://dhruv-kapri.github.io/**

Static HTML and CSS on GitHub Pages, no build step. Light by default with a dark-mode toggle.

- `index.html`: the page
- `style.css`: styles (bump the `?v=` query in `index.html` after edits; Pages caches CSS for 10 minutes)
- `cv.pdf`: current CV
- `assets/`: images
